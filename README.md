# Anniversary Site — Our Love Story

A heartfelt single-page anniversary website celebrating another year together. Styled with a soft pink theme, it walks through the story from "I do" to everyday moments — laughter, challenges, and quiet mornings — all in one self-contained HTML page.

## Features

- Single-file static website — no build step, no dependencies
- Romantic pink-themed design with inline CSS
- Fully responsive layout for mobile and desktop
- Easy to customize: edit `index.html` directly

## Tech Stack

- HTML5, CSS3 (inline styles), vanilla JavaScript

## Quick Start

Open `index.html` in any browser — that's it. Or serve it locally:

```bash
npx serve .
```
